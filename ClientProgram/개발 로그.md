### 특이 사항
#### 그리는 방식
그리는 방식, 지우는 방식을 svg 방식으로 바꿨음.

#### 데이터 표현

1. 선을 그린다는 것을 표현하는 방법
    - 0 (int32)//앞으로의 데이터는 한 선을 그리는 데이터라는 뜻
    - 해당 획의 id (int64)
    - 이 획을 그린 사람의 id // 아직 추가 안 했어요.
    - 선 두께 (int32)
    - 선 색 (int32)
    - 선에 포함된 점의 개수 (int32)
    - x1 (int32)
    - y1 (int32)
    - x2 (int32)
    - y2 (int32)   
    ...
    - yn (int32)   //선에 포함된 점의 개수를 n이라고 했을 때.

를 직렬화 해서 한 번에 서버로 보냄.

2. 선을 지운다는 것을 표현하는 방법
    - 1 (int32) //앞으로의 데이터는 지우는 것과 관련 있는 데이터라는 뜻.
    - id (int64) // 지울 선이 가지고 있는 id.

를 직렬화 해서 한 번에 서버로 보냄.

## ver 1.0
### 기능

#### 1. 그림판 생성
프로그램 열면 윈도우만 열림.   
버튼 누르면 사용자에게 그릴 그림판 크기를 입력받으면 그 크기의 그림판이 나옴.

이유:    
나중에 어떤 크기의 그림판이 필요할지 달라질 수 있으니 바꾸기 편하게 만들기 위해서.

#### 2.검정색 펜으로 그리기
흰 보드에 마우스 우클릭을 통해서 그림 그릴 수 있음.

이유:    
제가 공부하는 목적도 포함해서, 일단 쉽게 만들었어요.
